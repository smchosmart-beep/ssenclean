# 쎈Clean (SEN Clean) 1.0 — spec.md

> 쎈(SEN) 도구 제품군 4번째 프로그램. 교사 PC의 개인정보·폰트·암호·보안 설정·광고 프로그램을 **한 화면에서 확인하고 버튼 하나로 해결**하는 Windows 설치형 도구.

---

## 0. 제품 원칙 (모든 기능의 판단 기준)

1. **30초 원칙**: 컴퓨터를 잘 못 다루는 교사가 설명서 없이 30초 안에 원하는 작업을 끝낼 수 있어야 한다.
2. **관리자 작업은 확인 창 [예]로**(1.3.0): 기본은 일반 권한으로 동작한다. 관리자 권한이 필요한 작업은 버튼을 누르면 Windows 확인 창(UAC)이 뜨고 사용자가 [예]를 누르면 처리한다(관리자 실행 도우미 `core/platform/elevate-win.js`: 정해진 작업만, 작업 목록은 SHA-256 확인). "정보 담당 선생님께" 안내는 쓰지 않는다. 학교 PC와 집 PC는 같다고 본다(학교 정책·학교 서버 계정 분기 없음).
3. **외부 전송 없음**: 파일 내용·검사 결과는 PC 밖으로 나가지 않는다. 인터넷은 업데이트 버전 확인에만 사용한다.
4. **지우기 전 확인, 항상 되돌리기**: 자동 삭제는 없다. 사용자가 고른 것만 처리하고, 처리한 작업은 되돌릴 수 있어야 한다(완전삭제 제외).
5. **쉬운 말**: 전문 용어를 화면에 노출하지 않는다(12.1 용어표).
6. **암호를 저장하지 않는다**: 쎈Clean은 어떤 암호도 저장·기억하지 않는다.
7. **단정하지 않는다**: 저작권·악성 여부를 확정하지 않고 "사용 주의", "의심돼요"로 표현한다.

## 1. 기술 스택

쎈PDF와 동일한 구조를 따른다.

| 구분 | 사용 기술 |
|---|---|
| 데스크톱 앱 | Electron 41.10.7 (쎈PDF와 동일) |
| 화면 | HTML + CSS + 순수 JavaScript(ES Modules), 프레임워크 없음 |
| 파일·시스템 접근 | Electron 메인 프로세스 → preload → IPC (화면에는 필요한 함수만 노출) |
| 무거운 작업 | Electron `utilityProcess` (개인정보 검사) |
| Win32 API 호출 | `koffi` (Node FFI, 컴파일 불필요) |
| COM 조회 (Windows 업데이트 등) | PowerShell 1회성 호출, 실패 시 "확인할 수 없어요"로 대체 |
| OOXML·HWPX 해제 | `fflate` |
| HWP 5.0 (구형) | `cfb` + `fflate` + 자체 레코드 파서 |
| XLSX·XLS | 자체 리더 `sheets.js` (xlsx, xls BIFF8, HTML로 저장된 xls). SheetJS는 보안 문제로 쓰지 않음 |
| PDF 텍스트 | PDF.js 6.4.299 (5.6.83~6.2.107은 악성 PDF 코드 실행 취약점이 있어 사용하지 않음) |
| 폰트 메타데이터 | 자체 리더 (name·OS/2 테이블만 읽음, TTF/OTF/TTC) |
| 설정 저장 | 경로·목록·되돌리기 기록은 `userData` 폴더 JSON, 화면 상태(마지막 탭 등)만 localStorage |
| 테스트 | Playwright (`_electron`) + Node.js |
| 패키징 | ASAR |
| 설치파일 | NSIS **사용자별 설치(per-user)** + 무설치 ZIP |
| 대상 | Windows 10·11, x64 |

> **설치 방식 주의**: 설치 때 확인 창이 뜨지 않도록 NSIS는 반드시 `%LOCALAPPDATA%\Programs\SenClean`에 설치하는 사용자별 설치로 만든다(UAC 창이 뜨면 안 됨).

### 1.1 보안 설정
- `contextIsolation: true`, `nodeIntegration: false`, `sandbox: true`
- IPC 채널은 화이트리스트 방식. 렌더러는 임의 경로·임의 명령을 넘길 수 없고, 메인 프로세스가 정해진 동작만 수행
- 외부 웹 콘텐츠 로드 없음, CSP 적용

### 1.2 플랫폼 어댑터
Windows 의존 기능은 `core/platform/` 아래 어댑터 인터페이스로 분리하고, 테스트용 mock 구현을 함께 둔다(13장).

## 3. 대시보드 (첫 화면, "점검 현황")

### 3.1 화면
```
┌──────────────────────────────────────┐
│  ⚠ 해결할 일이 4개 있어요              │
│  마지막 점검: 방금 전   [다시 점검]     │
└──────────────────────────────────────┘

🔴 PC암호가 없어요                     [암호 만들기]
🔴 화면보호기가 꺼져 있어요             [안전하게 설정]
🟠 브라우저에 의심 항목 3개             [청소하기]
🟠 크롬 업데이트가 있어요               [업데이트]
🟢 PC암호 — 다음 변경까지 D-42
🟢 폰트 — 문제없어요
🟢 개인정보 파일 — 지난 검사 9월 28일, 0개   [지금 검사]
⚪ 바탕화면 — 파일 127개                [정리하기]
```
- 모두 해결되면 상단에 크게 **"✓ 내 PC가 안전해요"**.
- 점수는 쓰지 않는다. "해결할 일 N개"만 표시한다.
- 카드 순서: **사이드바 메뉴 순서로 고정**(1.3.0, 개인정보 파일 → 폰트 → PC암호 → 화면보호기 → 업데이트 → C드라이브 → 브라우저 → 바탕화면 → IP 주소). 급한 정도는 색·태그와 "해결할 일 N개"로 보여 준다.
- 점검 중인 줄은 이름과 함께 "○○ 확인 중…" + 회색 '점검 중' 태그, 메뉴 점은 회색 깜빡임. 20초 넘으면 안내, 2분 넘으면 "확인할 수 없어요" + [다시 확인]. 점검 중에는 [다시 점검] 비활성.
- 카드 버튼은 해당 메뉴로 이동하거나, 단순 동작(화면보호기 안전 설정 등)은 그 자리에서 실행 후 카드 갱신.

### 3.2 점검 방식
| 항목 | 앱 실행 시 자동 점검 | 비고 |
|---|---|---|
| PC암호 (유무, D-day) | ✓ | |
| 화면보호기 | ✓ | |
| 업데이트 | ✓ | 인터넷 필요, 실패 시 ⚪ |
| 폰트 | ✓ | |
| 브라우저 광고 항목 | ✓ | 빠른 점검(바로가기·시작 프로그램·인터넷 바로가기) |
| 바탕화면 파일 수 | ✓ | 회색 정보 카드 |
| 개인정보 파일 | ✗ | 수 분 소요. 마지막 검사 결과(날짜·개수)만 표시, [지금 검사] |
| C드라이브 남은 공간 | ✓ | 10% 미만(또는 10GB 미만) 🔴, 15% 미만(또는 20GB 미만) 🟠 |

- 자동 점검은 전체 5초 이내 목표. 항목별 비동기 실행, 끝나는 대로 카드 채움.
- 점검 결과 요약(개수·상태만)은 `userData/last-check.json`에 저장. **개인정보 원문이나 마스킹된 문맥도 저장하지 않는다.**

## 4. 메뉴 1 — 개인정보 파일

내 PC에 흩어진 개인정보 포함 파일을 찾아 보여주고, 한 번에 지운다.

### 4.1 흐름
1. **어디를 찾을까요?**
   - 기본: ☑ 바탕화면 ☑ 문서 ☑ 다운로드
   - [폴더 추가] / [내 PC 전체] (D: 등 다른 드라이브 포함)
2. **[개인정보 찾기]** → 진행 화면: 진행 막대, "1,240개 중 312개 확인 중", 찾는 즉시 결과 목록에 추가, [멈추기]
3. **결과 화면**: 파일 카드 목록 + 오른쪽 미리보기
4. 체크 → **[선택한 12개 지우기]** → 확인 창 1회 → 완료

### 4.2 검사 대상 형식 (1.0)
| 형식 | 방법 |
|---|---|
| .pptx .docx | ZIP 내부 XML 텍스트 추출 (fflate) |
| .xlsx | ZIP 내부 sharedStrings·시트 XML (sheets.js) |
| .hwpx | ZIP 내부 `Contents/section*.xml` |
| .hwp (5.0) | OLE(cfb) → `BodyText/Section*` 스트림 → 압축 해제(raw deflate) → `HWPTAG_PARA_TEXT`(태그 67) 레코드에서 UTF-16LE 텍스트 추출, 제어문자 제거. 배포용·암호 문서는 "확인 불가" |
| .xls | BIFF8 직접 읽기(SST·CONTINUE 포함), HTML 형식 xls도 지원 (sheets.js) |
| .pdf | PDF.js 텍스트 레이어. 텍스트가 없으면(스캔본) "확인 불가 — 1.1에서 지원" |
| .csv .txt | 인코딩 자동 판별(UTF-8/CP949) 후 텍스트 |

- 1.0 제외: 이미지·스캔 PDF OCR, .doc/.ppt(구형)
- 암호 걸린 파일·손상 파일 → "열 수 없어요" 그룹으로 따로 표시

### 4.3 검사 제외 규칙
- 시스템 폴더(`Windows`, `Program Files*`, `AppData`, `$Recycle.Bin`) 제외
- 파일 1개 100MB 초과 → 건너뜀(목록에 "너무 커서 건너뜀" 표시)
- **OneDrive 등 클라우드 전용 파일**(오프라인/`RECALL_ON_DATA_ACCESS` 속성)은 열면 다운로드가 일어나므로 건너뛰고 "클라우드에만 있는 파일" 표시
- 숨김 파일 제외, 바로가기 따라가지 않음

### 4.4 탐지 항목과 규칙
| 항목 | 위험도 | 규칙 |
|---|---|---|
| 주민등록번호 | 🔴 | `\d{6}[-\s]?[1-8]\d{6}` + 앞 6자리가 실제 날짜(월 01–12, 일 유효) + 성별 자리 1–8. **검증식(체크섬)은 쓰지 않는다** (2020.10 이후 발급분은 뒷자리가 임의번호) |
| 외국인등록번호 | 🔴 | 주민번호와 같은 형식, 성별 자리 5–8 |
| 여권번호 | 🔴 | 구형 `[MSRODG]\d{8}`, 신형 `[MSRODG]\d{3}[A-Z]\d{4}` + 주변 30자 안에 "여권" 키워드 |
| 운전면허번호 | 🔴 | `\d{2}-?\d{2}-?\d{6}-?\d{2}` + 주변 "면허" 키워드 |
| 계좌번호 | 🟠 | 숫자·하이픈 10–16자리 + 주변 30자 안에 "계좌/은행/예금주" 또는 은행명 키워드 |
| 휴대전화 | 🟠 | `01[016789][-\s.]?\d{3,4}[-\s.]?\d{4}` |
| 이메일 | 🟡(노랑, 주황 계열) | 표준 이메일 패턴 |

- 오탐 줄이기: 앞뒤가 숫자로 이어지는 경우(더 긴 숫자열의 일부) 제외
- 파일 위험도 = 포함 항목 중 최고 위험도

### 4.5 결과 화면
**파일 카드**
```
🔴 3학년 2반 명단.xlsx
   바탕화면 › 2025 업무
   주민번호 12 · 전화번호 30
   마지막 수정: 1년 전
```
- 경로는 사용자 폴더 기준 쉬운 경로(`바탕화면 › …`)로 표시
- 정렬: [위험한 순] [오래된 순] [폴더별]
- "마지막으로 연 날짜"가 아니라 **"마지막 수정"**으로 표시 (Windows 열람 시각 기록이 꺼져 있는 경우가 많음)

**미리보기 패널 (오른쪽)**
- 발견된 부분만 앞뒤 문맥 20자와 함께 표시, 값은 마스킹
  - 주민번호 `900101-1******`, 전화 `010-****-5678`, 계좌 `123-***-****89`
- 엑셀: 해당 행 최대 5줄, 셀 위치(B12) 표시
- [파일 위치 열기] (탐색기에서 해당 파일 선택 상태로 열기)
- 미리보기 데이터는 메모리에만 두고 화면 닫으면 폐기

### 4.6 지우기
- 기본: **휴지통으로 보내기** (`shell.trashItem`) — 휴지통에서 복구 가능
- 옵션: ☐ 복구하기 어렵게 지우기 — 무작위 덮어쓰기 1회 후 삭제
  - 안내 문구: "SSD에서는 완벽한 복구 차단을 보장할 수 없어요"
  - 이 옵션 선택 시 확인 창에 "되돌릴 수 없어요"를 빨간 글씨로

| 분류 | 조건 | 기본 처리 |
|---|---|---|
| 🟢 안심 | 허용 목록 DB의 패밀리명과 일치 (Windows 기본, 한컴오피스 동봉, MS 오피스 동봉, 학교안심) **또는** 라이선스 필드에 SIL OFL 등 공개 라이선스 명시 | 표시만 |
| 🟠 사용 주의 | 허용 목록에 없고, 제작사·저작권 필드가 상용 폰트 제작사 DB와 일치 | 기본 체크 |
| ⚪ 확인 필요 | 위 둘 다 아님(정보 없음·판단 불가) | 체크 해제 상태로 표시만 |

- 카드에 표시: 폰트 이름, 제작사, 분류 이유 한 줄, 미리보기 문장("가나다 쎈Clean ABC 123")

### 5.4 정리 동작
1. 해당 폰트를 쓰는 프로그램(한글, 파워포인트 등)이 열려 있으면 "한글·파워포인트를 닫아 주세요" 안내 후 진행
2. `HKCU` 폰트 레지스트리 값 삭제 → `RemoveFontResourceW` → 파일을 `userData/font-backup/<날짜>/`로 이동
3. 파일이 잠겨 이동 실패 시: 레지스트리 값만 지우고(다음 로그인부터 로드 안 됨) "다시 켤 때 마저 정리할게요" 표시, 다음 실행 시 재시도
4. `WM_FONTCHANGE` 브로드캐스트
5. 완료 후 안내: "이 폰트로 만든 문서는 다른 폰트로 보일 수 있어요"
6. 되돌리기: 백업 파일 복원 + 레지스트리 재등록 + `AddFontResourceW`

### 5.5 학교안심폰트 설치
- 상태: "설치되어 있어요 ✓" 또는 [학교안심폰트 설치하기]
- 설치: 내 계정 폰트 폴더에 복사 → HKCU 레지스트리 등록 → `AddFontResourceW` → `WM_FONTCHANGE`
- 폰트 파일 공급 방식은 **라이선스 재배포 허용 여부 확인 후 결정** (14장)
  - 허용: 설치파일에 포함(오프라인 설치)
  - 불허: 공식 배포처 다운로드 후 설치, 또는 배포처 링크 안내

### 6.2 상태 감지

|---|---|---|
| 계정 종류 | 도메인 가입 여부(`NetGetJoinInformation`), Microsoft 계정 연결 여부(레지스트리) | "확인할 수 없어요" |

- 기준 90일, 설정에서 30/60/90/180일 변경 가능
- 🟢 15일 이상 남음 / 🟠 14일 이하(대시보드 '해결할 일'에 포함) / 🔴 기한 지남("변경일이 12일 지났어요")
- 암호 변경 성공 시 즉시 재계산
- **알림 기능 없음** (확정)

### 6.4 암호 만들기·바꾸기 (쎈Clean 안에서)
**PC 전용 계정**
```
암호 바꾸기
  현재 암호     [          ]  (암호가 없으면 이 칸 숨김)
  새 암호       [          ]
  새 암호 확인   [          ]
  [바꾸기]  [취소]
```
- `NetUserChangePassword(null, 사용자, 현재, 새)` 호출
- 오류 문구
  - 현재 암호 틀림 → "지금 쓰는 암호가 맞지 않아요" (연속 3회 실패 시 "계정이 잠길 수 있어요" 경고 후 입력 잠시 비활성)

- 이 API가 막힌 PC → 보조 경로: `ms-settings:signinoptions` 열고 "'암호' 옆 [추가] 또는 [변경]을 누르세요" 한 줄 안내

### 6.5 범위 밖 (확정)
- 암호 저장·기억, 암호 자동 교대 변경: **하지 않는다**

3. **큰 파일 목록**(찾은 뒤): [전체/동영상/설치파일] 탭, [오래된 순](기본)/[큰 순], 줄마다 이름·종류·짧은 위치(앞 두 단계, 전체는 마우스 오버)·날짜+"N개월 전"·크기·[위치], 이름·크기가 같은 파일엔 "같은 파일 N개". 아래 고정 막대: 전체 선택, [1년 넘은 것 선택], 선택 합계, "바탕화면에 '옮긴 파일' 바로가기 만들기"(기본 켬), [D드라이브로 옮기기]/[다른 드라이브로 옮기기], [지우기].

- **찾는 범위**: C:\ 전체에서 Windows·Program Files·ProgramData·휴지통·시스템 폴더, 각 사용자 AppData, 연결 폴더(정션), 클라우드에만 있는 파일은 제외.
- **찾는 파일**: 동영상(mp4·mkv·avi·mov·wmv 등) 50MB 이상 / 설치파일 5MB 이상 — iso·msi·msix는 어디서나, exe는 이름에 setup·install·설치·update 등이 있거나 다운로드 폴더에 있을 때.
- **옮기기**: `D:\C드라이브에서 옮긴 파일\<원래 위치>\파일`. 다른 드라이브면 복사 → 크기 확인 → 원본 삭제. 재생 중이라 원본을 못 지우면 복사본을 지우고 "열려 있어서 못 옮겼어요". 공간이 모자라면 시작하지 않음. 진행률·멈추기.
- **드라이브 고르기**: 옮길 드라이브가 하나면 확인 창, 여러 개면 고르기 창(남은 공간 막대, '추천'=남은 공간이 가장 많은 고정 드라이브, 공간 부족은 선택 불가, USB는 "빼면 열 수 없어요" 주의). 고른 드라이브를 기억해 다음에 맨 위.
- **바로가기**: 파일별 바로가기는 만들지 않는다. 바탕화면에 '○드라이브로 옮긴 파일' 폴더 바로가기 1개만(이미 있으면 그대로).
- **되돌리기**: 마지막 옮기기 기록(`cdrive-undo/*.json`)으로 원래 자리로. 그 드라이브에 옮긴 파일이 하나도 안 남으면 빈 폴더와 바탕화면 바로가기도 지운다.
- **지우기**: 휴지통으로. 휴지통에 있어도 공간을 차지하므로 [휴지통 비우기]를 함께 안내.

> **1.5.0 변경**: [휴지통 비우기]는 Windows 휴지통과 같이 **모든 드라이브** 휴지통을 비운다(`SHEmptyRecycleBinW(NULL)`). 카드에는 합계와 C드라이브 몫, 확인 창에는 드라이브별 크기. 남은 파일이 있으면 "일부는 비우지 못했어요". "같은 파일 N개"는 이름·크기가 같고 **내용도 같을 때만**(256MB 이하 전체 SHA-1, 초과는 앞·가운데·끝 1MB씩).
- 프로그램 제거: `control appwiz.cpl`

### 10.4 같이 찾기
| 항목 | 판정 |
|---|---|
| 설치파일 | .exe/.msi 중 이름에 setup/install/설치 포함 또는 설치 프로그램 서명 정보 보유 |

## 11-A. 메뉴 9 — IP 주소 · PC 사양 (1.6.0)

- **불러오기는 수동**: 화면에 들어오거나 점검 현황을 열 때 IP를 읽지 않는다. [불러오기]/[다시 불러오기]를 누를 때만 IP·연결 상태·PC 사양을 읽고 `pc-info.json`에 저장해 두었다가 다음에 그대로 보여 준다("○월 ○일 00:00에 불러옴"). IP를 바꾸거나 [원래대로] 하면 저장한 IP도 새 값으로.
- **PC 사양**(일반 권한 PowerShell CIM): PC 모델(Win32_ComputerSystem), CPU(Win32_Processor), RAM 합계 + 모듈별 크기×개수·제조사(JEDEC 코드 → 삼성·SK하이닉스 등)·부품번호·속도(Win32_PhysicalMemory), SSD/HDD 모델·용량(Get-PhysicalDisk, USB 제외, 없으면 Win32_DiskDrive), 모니터 모델(root\wmi WmiMonitorID, 이름이 없으면 제조사 + 제품코드), 프린터 모델(Win32_Printer 드라이버 이름, PDF·XPS·팩스·원노트 등 가상 프린터 제외, 기본 프린터 표시). 여러 개는 ` / `로 잇는다. 사양을 못 읽어도 IP는 보여 준다.
- **메시지**: `[쎈Clean IP 정보]` 메시지 끝에 `── PC 사양 ──` 다음 `PC 모델 …`, `CPU …`, `RAM …`, `SSD …`, `모니터 …`, `프린터 …` 줄을 붙인다. 정보부장 쪽은 줄 맨 앞 이름으로 읽고(구분선이 없어도 됨), IP는 사양 앞부분에서만 찾는다.
- **대장**: 같은 PC(MAC)면 갱신. 사양 없는 예전 메시지로 다시 받아도 저장된 사양은 지우지 않는다. 목록 줄에 사양 한 줄, 찾기에 모델명 포함. CSV에 `PC모델, CPU, RAM, SSD, 모니터, 프린터` 열 추가(가져오기도 지원).
- **점검 현황 카드**: 불러온 적 없으면 "IP 주소·PC 사양 - 아직 불러오지 않았어요" + [불러오기], 있으면 저장한 IP와 불러온 날.

### 11-A.1 1.7.0 변경
- RAM·SSD·HDD는 용량만(`RAM 32GB`, `SSD 1TB + 500GB`, `HDD 500GB`), 메시지에 `HDD` 줄 추가. 종류를 모르는 저장장치는 SSD 칸에 `(종류 모름)`. 1.6.0 형식은 읽을 때 변환.
- 대장은 표. 칸: 교실·PC 이름·IP·MAC·CPU·RAM·SSD·HDD·모니터·프린터·구입 시기·받은 날·상태 + 관리(맨 오른쪽 고정). 머리줄 끌기(8px 넘게 움직이면 끌기, 그냥 누르면 정렬) 또는 [칸 순서] 창으로 순서 변경 → `ip-registry.json`의 `columns`에 저장, CSV 내보내기도 그 순서(화면에 없는 열은 뒤). 
- 구입 시기 `purchase`: `YYYY.MM` 또는 `YYYY`로 맞춰 저장, 잘못된 값은 거부. 교사 메시지로 덮어쓰지 않음.

## 12. 공통 사항

### 12.1 용어표 (화면 문구 기준)
| 쓰지 않는 말 | 쎈Clean 표현 |
|---|---|
| 검출 | 찾았어요 |
| 파기 / 완전삭제 | 복구하기 어렵게 지우기 |
| 예외 처리 | 이 파일은 괜찮아요 |
| 고유식별정보 | 주민번호·여권번호 등 |
| 검사 경로 설정 | 어디를 찾을까요? |
| 저작권 위반 폰트 | 사용 주의 폰트 |
| 애드웨어 / PUP | 광고 프로그램 |
| 프록시 | 인터넷 연결 설정 |
| 서비스 / 레지스트리 | (노출하지 않음) |
| 관리자 권한 필요 | Windows 확인 창이 뜨면 [예]를 누르세요 (취소하면 "취소했어요") |
| 로컬 계정 | 이 PC 전용 계정 |

### 12.2 userData 저장 파일
| 파일 | 내용 |
|---|---|
| `settings.json` | 바탕화면 정리 조합, D-day 기준일, 화면보호기 대기시간, 수동 입력 암호 변경일 |
| `last-check.json` | 대시보드 항목별 상태·개수·시각 (개인정보 원문·문맥 저장 금지) |
| `exclusions.json` | 개인정보 제외 파일 키 |
| `font-backup/` | 정리한 폰트 파일 + 등록 정보 |
| `desktop-undo/` | 바탕화면 정리 이동 기록 |
| `browser-undo/` | 바로가기·시작 프로그램·예약 작업·프록시 원래 값 |
| `screensaver-undo.json` | 화면보호기 변경 전 값 |

- 로그 파일에 파일 내용·암호·개인정보를 남기지 않는다. 오류 로그는 동작 이름과 오류 코드만.

### 12.3 오류 처리 원칙
- 모든 오류는 "무슨 일이 생겼는지 + 지금 할 수 있는 것" 한 문장
  - 예: "파일이 열려 있어서 못 지웠어요. 한글을 닫고 다시 눌러 주세요."
- 권한 부족(ERROR_ACCESS_DENIED) → 관리자 권한으로 다시 시도(확인 창)

### 12.4 접근성
- 키보드만으로 모든 버튼 조작 가능, 포커스 표시 명확
- 색만으로 상태를 전달하지 않는다(아이콘·문구 병기)
