## 쎈Clean 2.0.1

교사 PC의 개인정보 파일·폰트·PC암호·화면보호기·업데이트·바탕화면·브라우저 광고·IP 주소·C드라이브 공간를 한 화면에서 확인하고 버튼 하나로 해결하는 Windows 프로그램입니다.

### 내려받기
[SenClean_Setup_2.0.1.exe](https://github.com/smchosmart-beep/ssenclean/raw/downloads/SenClean_Setup_2.0.1.exe) — Windows 10·11 (64비트)

### 설치
1. 위 파일을 내려받아 실행합니다. 관리자 암호 없이 내 계정에 설치됩니다.
2. "Windows의 PC 보호" 창이 뜨면 **[추가 정보] → [실행]**을 누르세요. (코드 서명 전 버전)

### 2.0.1에서 바뀐 점
- 한글 [업데이트 확인]을 누르면 한컴 업데이트 창이 실제로 열리도록 고쳤습니다.

### 1.0.1에서 바뀐 점
- 크롬 업데이트 판정을 이 PC의 구글 업데이트에 직접 확인하도록 바꿨습니다.
- 크롬 [업데이트]를 쎈Clean 안에서 진행하고, 끝나면 [크롬 다시 켜기]로 적용합니다.
- 한글 [업데이트 확인]이 한컴 업데이트 프로그램을 바로 엽니다.
