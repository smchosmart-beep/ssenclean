# 쎈클린 (SEN Clean) 1.0

교사 PC의 개인정보 파일·폰트·PC암호·화면보호기·업데이트·바탕화면·브라우저 광고를 **한 화면에서 확인하고 버튼 하나로 해결**하는 Windows 설치형 도구입니다. 쎈(SEN) 제품군 4번째 프로그램입니다.

- 회원가입·광고·결제 없음
- 파일은 PC 밖으로 나가지 않음 (업데이트 버전 확인에만 인터넷 사용)
- **관리자 권한 없이 동작** (교사 계정 기준). 권한이 필요한 항목은 "정보 담당 선생님께 요청하세요"로 안내
- 암호를 저장하지 않음
- 지우기 전에 항상 확인, 옮기거나 바꾼 것은 되돌리기 제공

기능 명세는 `docs/spec.md`, 디자인 규칙은 `docs/DESIGN.md`에 있습니다.

---

## 1. 준비

Windows 10·11 x64 PC에 [Node.js](https://nodejs.org) 20 이상(LTS)을 설치합니다.

```bat
cd sen-clean
npm install
```


## 2. 실행

| 명령 | 설명 |
|---|---|
| `npm start` | 이 PC에서 실제로 실행 (Windows 전용) |
| `npm run start:mock` | **연습용 가짜 PC**로 실행. 실제 파일·설정을 건드리지 않음. 화면 상단에 "연습용 가짜 PC" 표시 |

가짜 PC는 `%TEMP%\senclean-mock` 폴더에 만들어집니다. 처음 상태로 돌리려면 이 폴더를 지우세요.

## 3. 테스트

| 명령 | 내용 |
|---|---|
| `npm test` | 개인정보 탐지 규칙, 문서 파서(hwp·hwpx·xlsx·xls·docx·pptx·pdf·csv·txt), 메뉴별 서비스 35개 테스트 |
| `npm run test:e2e` | 가짜 PC에서 쎈클린을 실제로 띄워 대시보드부터 브라우저 청소까지 10개 흐름을 클릭으로 검증 |

## 4. 설치파일 만들기

**Windows PC에서** 실행합니다.

```bat
npm run dist
```

`dist` 폴더에 두 파일이 생깁니다.

- `SenClean_Setup_1.0.0.exe` — 설치파일. **사용자별 설치**(`%LOCALAPPDATA%\Programs\쎈클린`)라서 관리자 권한(UAC 창) 없이 설치됩니다.
- `SenClean_1.0.0_portable.zip` — 무설치 버전

> 리눅스·맥에서는 설치파일(NSIS)을 만들려면 Wine이 필요합니다. Windows에서 만드는 것을 권장합니다.

## 5. 폴더 구조

```
sen-clean/
├─ electron/          main.js(창·보안·IPC), preload.js(화면에 허용한 채널), services.js(서비스 조립·채널 표)
├─ core/
│  ├─ platform/       win32.js·native.js(Windows API, koffi) / mock.js·mock-seed.js(가짜 PC)
│  ├─ privacy/        detectors(탐지 규칙) · parsers(문서 텍스트 추출) · scan-core · scan-worker(별도 프로세스) · service
│  ├─ fonts/          fontinfo(폰트 이름표 읽기) · classify(안심/주의/확인 필요) · service
│  ├─ password.js  screensaver.js  updates.js  uninstall.js  desktop.js  browser.js  dashboard.js  store.js
├─ renderer/          index.html · styles/app.css(디자인 토큰) · js/(화면)
├─ data/              font-db.json(폰트 분류 DB) · adware-db.json(광고 프로그램 DB)
├─ assets/            fonts(Cafe24 PRO Slim Air·Bold, 학교안심 자연) · logo.svg · icon
├─ tests/             unit · e2e
└─ docs/              spec.md · DESIGN.md
```

화면(renderer)은 `preload.js`에 적힌 채널만 부를 수 있고, 지우기·옮기기는 **메인 프로세스가 방금 검사한 목록에 있는 파일만** 처리합니다. 화면이 임의 경로를 넘겨도 지워지지 않습니다.

## 6. 실기 점검 체크리스트 (교사 계정, 관리자 권한 없음)

리눅스 개발 환경에서는 Windows API를 직접 실행할 수 없어서, 아래 항목은 **실제 학교 PC에서 확인**해야 합니다. 각 항목이 실패해도 프로그램은 멈추지 않고 "확인할 수 없어요"나 안내 문구로 대체되도록 만들어 두었습니다.

### 설치
- [ ] `SenClean_Setup_1.0.0.exe`가 UAC 창 없이 설치되는지
- [ ] SmartScreen 경고가 뜨는지 (뜨면 "추가 정보 → 실행" 안내 필요, 코드 서명 검토)
- [ ] 교육청 백신이 쎈클린을 차단하지 않는지 (레지스트리·예약 작업을 다루므로 오탐 가능)

### PC암호 (spec 14-2~5)
- [ ] 암호가 없는 계정에서 "⚠ 없음", 있는 계정에서 "있음"으로 나오는지
- [ ] 계정 잠금 횟수에 영향이 없는지 — 암호 유무 확인에 빈 암호 로그인 시도를 쓰기 때문에 **하루 1회만** 확인하고 결과를 기억함. 이벤트 뷰어 보안 로그의 로그온 실패(4625)가 하루 1건 이하인지 확인
- [ ] 마지막 변경일이 맞게 나오는지 (`net user 사용자명`의 "마지막으로 암호 설정한 날짜"와 비교)
- [ ] 쎈클린 안에서 암호 만들기·바꾸기가 되는지, 틀린 현재 암호·짧은 암호에서 오류 문구가 맞는지
- [ ] Microsoft 계정으로 로그인한 PC에서 "Microsoft 계정"으로 나오는지

### 화면보호기
- [ ] [안전하게 설정하기] 후 `화면 보호기 설정` 창에서 "(없음)" → "빈 화면", 10분, "다시 시작할 때 로그온 화면 표시" 체크로 바뀌었는지
- [ ] 10분 뒤 실제로 잠기는지, [원래대로]가 되는지

### 개인정보 파일
- [ ] 실제 학교 문서(hwp·hwpx·xlsx·나이스에서 내려받은 xls)에서 주민번호·전화번호를 찾는지
- [ ] 한글로 연 문서를 지우려 할 때 "열려 있거나 지울 권한이 없어요"로 나오는지
- [ ] OneDrive 바탕화면을 쓰는 PC에서 "클라우드에만 있는 파일"을 건너뛰는지
- [ ] 1만 개 이상 파일 폴더 검사 중에 화면이 멈추지 않는지

### 폰트
- [ ] 직접 내려받아 설치한 상용 폰트가 "사용 주의"로 나오는지
- [ ] 정리 후 한글·파워포인트 글꼴 목록에서 사라지는지, [되돌리기] 후 다시 보이는지
- [ ] 학교안심 글꼴 설치 후 한글 글꼴 목록에 보이는지

### 업데이트 (spec 14-6~9)
- [ ] 크롬 [업데이트]가 '크롬 정보' 화면을 여는지 (안 열리면 안내 문구로 대체)
- [ ] Windows 대기 업데이트 개수가 나오는지 (PowerShell 차단 PC는 마지막 설치일만 표시)
- [ ] 한글 버전이 나오는지, 한컴 업데이트 프로그램 경로가 맞는지 (`core/updates.js`의 `hancomUpdater` 후보 경로)
- [ ] 학교 오피스가 Click-to-Run인지, [업데이트]가 오피스 업데이트 창을 여는지

### 바탕화면 정리
- [ ] 정리·되돌리기 후 바탕화면 아이콘 배치가 크게 어긋나지 않는지
- [ ] 크롬·한글·나이스 바로가기가 그대로 있는지

### 브라우저 청소
- [ ] 크롬 바로가기 뒤에 광고 주소가 붙은 PC에서 찾고 고치는지 (작업 표시줄 고정 아이콘 포함)
- [ ] 시작 프로그램 끄기 후 `작업 관리자 → 시작 앱`에서 "사용 안 함"으로 보이는지
- [ ] nProtect·TouchEn·AnySign 등 보안 프로그램이 결과에 **나오지 않는지**
- [ ] 크롬을 닫지 않으면 기록 지우기가 멈추고 [모두 닫기] 안내가 나오는지

## 7. 배포 전에 정할 것

| 항목 | 내용 |
|---|---|
| 학교안심 글꼴 재배포 | 설치파일에 넣어 배포해도 되는지 KERIS 라이선스 확인. 안 되면 `assets/fonts/Hakgyoansim_*.ttf`를 빼고 `data/font-db.json`의 `schoolFonts.officialUrl`에 공식 배포처를 넣으면 화면이 자동으로 바뀜 |
| Cafe24 PRO Slim 임베딩 | 앱에 넣어 무료 배포해도 되는지 Cafe24 폰트 라이선스 확인 |
| 광고 프로그램 DB | `data/adware-db.json`은 널리 알려진 해외 애드웨어와 의심 패턴만 담은 초기값. 학교 PC에서 실제로 발견되는 국내 광고 프로그램 이름·제작사·도메인을 모아 보완 |
| 폰트 DB | `data/font-db.json`의 한컴오피스·MS오피스 동봉 폰트와 상용 제작사 목록을 실제 PC 기준으로 보완 |
| 코드 서명 | 서명 없는 설치파일은 SmartScreen 경고가 뜸 |

## 8. spec 대비 바뀐 점

- **폰트 정보 읽기**: `fontkit` 대신 폰트 파일의 이름표(name·OS/2 테이블)만 읽는 작은 리더를 직접 만들었습니다. 시스템 폰트 수백 개도 빠르게 읽고 의존성이 줄었습니다.
- **PDF.js 6.4.299**: 5.6.83~6.2.107 버전에 "악성 PDF를 열면 임의 코드 실행" 취약점(GHSA-hq66-cqwq-w95j)이 있어 수정된 버전을 씁니다. **쎈PDF(5.6.205)도 해당 범위라 업데이트를 권장합니다.**
- **엑셀 읽기**: npm의 SheetJS(xlsx 0.18.5)에 보안 문제가 있어 쓰지 않고, xlsx·xls(BIFF8)·HTML로 저장된 xls를 읽는 코드를 직접 만들었습니다(`core/privacy/sheets.js`). 외부 라이브러리 보안 경고 0건입니다.
- **PIN 행**: 관리자 권한 없이 확실하게 감지할 방법이 없어 1.0에서는 표시하지 않습니다(spec 6.2에서 허용한 대안).
- **문서 검사는 별도 프로세스**(Electron utilityProcess)에서 돌아 큰 PDF를 읽어도 화면이 멈추지 않습니다. 패키징된 상태(ASAR)에서도 동작을 확인했습니다.
